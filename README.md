# 로타디 — 로스트아크 랜덤 타워 디펜스

Next.js(App Router) + TypeScript + Tailwind CSS + Canvas 2D 기반 랜덤 타워 디펜스.
게임 로직(엔진)과 UI를 분리한 구조로, 데이터는 전부 에디터에서 CRUD로 관리합니다.

## 실행

```bash
cd LOATWDF
npm install
npm run dev        # http://localhost:3001
npm run typecheck  # tsc --noEmit
npm test           # vitest
```

## 화면 구성

카봇풍 캐릭터에 맞춘 카툰 UI입니다. 모든 면에 짙은 남색 굵은 외곽선과 아래로 떨어지는 두께를 주고, 버튼은 누르면 쑥 들어갑니다. 글꼴은 Lilita One(숫자·영문) · Black Han Sans(제목) · Jua(본문)를 Google Fonts에서 불러오고, 에디터만 읽기 편한 Gothic A1을 씁니다.

| 경로 | 설명 |
|------|------|
| `/` | 로비 — 원정지(스테이지 노드) · 난이도 · 직업(직업군 → 직업) 선택 후 출정. 이어하기 카드, 마지막 선택 기억 |
| `/game` | 전투 — 데스크톱(≥1024px)은 좌 직업·시너지 / 우 정보·보스·다음 웨이브·미션 / 하단 도크(스킬·대기석·소환·웨이브). 모바일은 세로 화면에 맞춰 맵을 90° 돌리고 하단 도크 + 바텀시트 |
| `/editor` | 데이터 에디터 허브 + 데이터 점검(전체 검증) + 백업(내보내기/가져오기) |
| `/editor/chapters` | 챕터/스테이지 — 맵·지역, 스테이지별 등장 적, 자동/수동 웨이브 구성 |
| `/editor/maps` | 타일 맵 에디터 — 경로 최대 3개, 건설 가능/차단 타일 |
| `/editor/towers` | 아군 캐릭터 — 등급, 다중 시너지(chip), 스탯, 스킬, 외형 |
| `/editor/enemies` | 적 캐릭터 — 스탯, 보스 여부, 특성, 외형 |
| `/editor/jobs` | 플레이어 직업 — 시너지 지역, 패시브/액티브 스킬 |
| `/editor/synergies` | 지역 시너지 — 단계별 효과 |
| `/editor/gachas` | 뽑기 — 비용, 등급별 확률, 지역 조건 |
| `/editor/missions` | 웨이브 미션 — 성공 조건, 보상 골드, 등장 웨이브 |
| `/editor/simulator` | 밸런스 시뮬레이터 — 자동 플레이 N회 실행 통계 |

## 게임 규칙

**전투**
- 적은 맵의 경로(최대 3개, 번갈아 배정)를 따라 이동하며 도착 시 목숨 -1, 0이면 패배
- 데미지: 물리/마법 분리, `감소율 = 방어력 / (방어력 + 100)`
- 치명타: 기본 10% / 160%, 시너지·직업으로 강화
- 마나: 전투 중 자연 회복 + 타격 획득, 가득 차면 스킬 자동 발동 (단일강타/광역/둔화/기절/연쇄/공속버프)
- 타워 타겟팅 모드: 선두 / 후미 / 최대 체력 / 보스 우선 (타워별 선택)
- 적 특성: 재생, 은신(가까운 타워만 타겟 가능), 분열(사망 시 자식 스폰), 방어 오라, 둔화·기절 면역

**캐릭터**
- 기본 데이터는 로스트아크 **인물 카드** 기반: 아군 147명(12개 대륙 시너지), 적 51종, 보스 73종
  - 우호적인 인물은 아군 타워, 적대적인 인물·마수는 적/보스 — 분류 기준과 목록은 `docs/card-roster.md`
  - 등급은 카드 등급 그대로(카드 영웅 = 게임 영웅), 에스더 11인도 전설 카드라 전설 등급
  - 스탯은 등급 × 역할(검사·마법사·성직자 등) 기본값이므로 에디터에서 조정
- 등급(캐릭터 고정): 일반 → 고급 → 희귀 → 영웅 → 전설 (에스더는 별도 등급 없이 전설에 포함 — 합성으로도 획득 가능)
- 캐릭터는 여러 지역 시너지를 가질 수 있음
- 뽑기: 종류/비용/등급별 확률/지역 조건(전체·선택·고정)을 에디터에서 정의
- 합성: 같은 등급 2개 → 1단계 상위 (최대 전설). 지역은 부모 각 40% / 그 외 20% 상속, 1%(직업 보너스 가산) 확률로 2단계 상위
- 시너지: 지역별 *서로 다른* 캐릭터 수로 단계 발동, 발동 효과는 **아군 전체** 적용. 직업이 특정 지역 카운트 +1
  - 대륙 단위 12개: 루테란(아르테미스·유디아 포함) · 베른 · 애니츠(토토이크 포함) · 섬 · 로헨델 · 욘 · 파푸니카 · 페이튼 · 아르데타인 · 슈샤이어 · 엘가시아 · 림레이크
  - 섬 출신 인물(기에나·프로키온의 바다 17명)은 "섬" 시너지 하나로, 요즈족 샨디·진저웨일은 림레이크
  - 단계 인원은 규모에 맞춤: 대형(루테란·베른·애니츠·섬) 2/4/6/8, 중형 2/4/6, 소형 슈샤이어 2/3/5 · 엘가시아 2/3 · 림레이크 2 (작은 대륙일수록 단계당 효과가 큼)

**플레이어 직업**
- 로스트아크 전 직업 30종 (전사 7 · 무도가 6 · 헌터 5 · 마법사 4 · 암살자 4 · 스페셜리스트 4)
  - 홈 화면 직업 목록은 직업군(`group`)별로 접고 펼침 — 직업군은 에디터에서 지정, 비워두면 "기타"
  - 직업 아이콘은 공식 홈페이지 CDN의 직업 엠블럼(`appearance.image`)을 그대로 불러와 표시 (이미지 파일은 저장소에 넣지 않음). 흰 실루엣을 마스크로 써서 상태별로 색을 입히고, 못 불러오면 이모지(`icon`)로 대신 표시
  - 스킬 이름은 직업 각인에서 따옴 (예: 버서커 광기/광전사의 비기). 가디언나이트·차원술사는 직업 콘셉트(엠버레스·차원 시계)
  - 직업군마다 고향 대륙 시너지 +1: 전사 슈샤이어 · 무도가 애니츠 · 헌터 아르데타인 · 마법사 로헨델 · 암살자 페이튼 · 스페셜리스트 림레이크. 가디언나이트는 고향 대륙이 없어 시너지 보너스 없음 (에디터에서 변경 가능)
- 패시브(상시) + 액티브(쿨다운 버튼: 아군 전체 강화 / 클릭 지점 범위 피해 / 골드 획득)
  - 패시브 종류: 시작 골드, 목숨, 뽑기 할인, 물리/마법 공격력, 공격속도, 치명타 확률·피해, 마나 회복, 처치 골드, 합성 대성공
- 액티브 스킬 총 사용 횟수는 난이도별 제한 (이지 15 / 하드 10 / 나이트메어 6)

**난이도 / 웨이브 / 경제**
- 난이도: 적 체력·방어 배수, 목숨, 시작 골드, 스킬 횟수 차등
- 웨이브: 스테이지별 자동 생성(5의 배수·마지막 = 보스) 또는 수동 구성(웨이브별 스폰 그룹/보스/배수)
- 웨이브 클리어 시 보너스 골드 + 보유 골드 이자(5%, 상한 30)
- 판매: 등급별 일반 5G · 고급 10G · 희귀 20G · 영웅 40G · 전설 80G (`SELL_REFUND_PCT` 25%)
  - 뽑기 기대 판매가가 비용보다 크면(직업 할인 포함) 골드가 무한히 늘어나므로 에디터가 경고
- **조기 호출**: 현재 웨이브 스폰이 끝났는데 적이 남아 있으면 다음 웨이브를 바로 부를 수 있음
  - 보너스 = 5G + 남은 적 수 × 2G (보스는 5마리로 계산), 최대 30G — `constants.ts`의 `EARLY_CALL_*`
  - 이어 붙인 웨이브의 클리어 보너스는 적 전멸 시 한꺼번에 지급 (이자는 1회)
- **웨이브 미션**: 준비 단계에서 시작한 웨이브마다 미션 1개 부여, 적 전멸 시 판정 → 성공하면 보상 골드
  - 조건: 목숨 손실 없이 / N초 이내 클리어 / 직업 스킬 없이 / 배치 N개 이하 / N초 이내 보스 처치
  - 배정은 시드+웨이브로 결정 (RNG를 소비하지 않아 뽑기 결과에 영향 없음), 수동 웨이브는 미션 고정 가능
  - 조기 호출로 이어 붙인 웨이브에는 새 미션이 붙지 않음

## 조작

- 하단 **소환** 버튼은 마지막으로 쓴 뽑기를 반복, **상점**에서 뽑기 종류(등급 확률 막대, 지역 선택) 고르기
- 대기석 카드 클릭 → 초록 타일 클릭으로 배치, 또는 카드를 맵으로 **드래그**
- 배치된 타워는 **드래그**로 이동
- 타워 선택 후 같은 등급(점선)을 클릭하면 합성 popover 표시
- 단축키: `Space` 웨이브 시작/조기 호출, `Esc` 일시정지 메뉴(효과음·속도·전투 기록·로비), `W` 회수, `F` 판매
- **빠른 메뉴**: 타워·대기석 카드를 길게 누르기(터치) 또는 우클릭(마우스) → 타겟팅 / 회수 / 판매 / 합성
- 타워에 마우스를 올리면 사거리 표시, 배치·이동 중에는 놓을 자리 기준 사거리 미리보기
- 상단 효과음 버튼(또는 일시정지 메뉴)으로 끄기/작게/크게 (브라우저에 저장)
- 웨이브 시작·보스 출현·전설 획득·클리어는 화면 중앙 리본 배너(상점 창 위에도 표시), 소환·미션·판매는 상단 알림으로 표시
- 웨이브 시작 버튼은 초록, 보스 웨이브는 빨강, 조기 호출은 하늘색으로 구분
- 전장 바닥은 챕터 지역(없으면 맵 지역)에 따라 15가지 지형: 초원(루테란) · 가을 들판(아르테미스) · 소금 사막(유디아) · 모코코 숲(토토이크) · 벚꽃 언덕(애니츠) · 사막(아르데타인) · 왕국 광장(베른) · 천상(엘가시아) · 설원(슈샤이어) · 정령의 숲(로헨델) · 화산 대장간(욘) · 마계(페이튼) · 열대 섬(파푸니카) · 바다 위 섬(섬) · 신비의 호수(림레이크). 칸·길·장식(나무, 야자수, 선인장, 수정, 버섯, 대나무, 기둥 …)과 전장 테두리 색이 바뀜
- 승리하면 남은 목숨으로 별점(잃지 않음 3개 / 절반 이상 2개 / 그 외 1개) 표시
- 시스템의 '동작 줄이기' 설정을 켜면 화면 흔들림 등 연출이 꺼짐
- 조준형 직업 스킬은 버튼 클릭 후 맵 클릭으로 시전
- 마우스/터치 공용 (모바일 브라우저에서 플레이 가능)

## 저장 / 재현성

- 엔진은 시드 RNG 기반으로 결정론적: 같은 시드 = 같은 결과 (결과 화면에 시드 표시)
- 웨이브 클리어 시점과 탭 닫기/숨김 시 localStorage에 자동 저장, 홈 화면에서 이어하기
- `engine.serialize()/restore()`는 순수 JSON이라 추후 서버 저장으로 교체 가능

## 데이터 / 그래픽 확장

- `/editor`에서 수정하면 즉시 `data/*.json`에 반영되고 다음 게임부터 적용
- 저장 시 검증 (`src/game/validate.ts`)
  - **오류** (저장 차단): 형식 위반, 없는 맵/적/미션 참조, 분열 순환, 시너지 단계 순서 등
  - **경고** (저장 후 표시): 시너지 정의 없는 지역, 해당 등급 캐릭터 없는 뽑기 확률, 뽑고 바로 팔면 이득인 뽑기 등
  - 다른 데이터가 참조 중인 항목(챕터가 쓰는 맵·적 등)은 삭제 불가, id는 변경 불가
- 에디터 허브의 **데이터 점검**에서 전체 오류/경고 확인, **내보내기/가져오기**로 전체 데이터를 JSON 파일 하나로 백업·복원
  (가져오기는 파일에 든 종류만 교체하며, 미리 검증해 오류가 있으면 적용하지 않음)
- 캐릭터 외형 우선순위: 스프라이트 시트 > 단일 이미지 > 도형 placeholder
- 에디터의 외형 섹션에서 이미지를 업로드하고 스프라이트 시트(프레임 크기, 줄별 애니메이션/fps)를 지정
- AI가 생성한 시트(가짜 투명 체커보드 배경, 불규칙한 프레임 간격)는 `scripts/fix_sprite_sheet.py`로 정리
  (`pip install pillow numpy` 필요, 사용법은 `docs/image-prompts.md`)
- 캐릭터마다 **이미지 생성 참고 설명(artRef)** 을 저장하면 에디터의 "📋 프롬프트 생성" 버튼이
  공통 스타일 + 캐릭터 외형 + 등급/역할 키워드를 조합한 완성 프롬프트를 만들어 줌
- 카드 인물 270명 전원의 artRef가 카드 일러스트를 보고 작성되어 있음 (보이는 외형만, 설정상 무기 등은 제외)
- 실제 로스트아크 캐릭터 외형 디스크립터는 `docs/character-references.md`, 조립 규칙은 `docs/image-prompts.md`
