# 카드 인물 분류표

인벤 카드 DB의 인물 카드를 아군(타워)·적·보스로 나눈 기준표입니다. `data/towers.json`, `data/enemies.json`은 이 표로 생성했고, 수치는 등급·역할별 기본값이므로 에디터에서 자유롭게 조정하면 됩니다.

- 등급: 카드 등급 그대로 (카드 영웅 = 게임 영웅). 에스더 11인은 `에스더` 등급
- 지역: 아군은 스토리상 소속 지역 → 같은 지역 시너지
- 역할: 공격 방식(사거리·스킬)을 정하는 분류. 아래 표의 기본값 참고
- id: 아군 `tw-c{카드코드}`, 적/보스 `en-c{카드코드}` (에스더 루테란은 기존 `tw-esther-luteran` 유지)

## 역할별 기본값
