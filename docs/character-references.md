# 로스트아크 캐릭터 레퍼런스 (이미지 생성용)

`image-prompts.md`의 공통 스타일 프롬프트에 붙여 쓰는 **캐릭터별 외형 디스크립터** 모음입니다.
각 항목의 `PROMPT` 줄을 에디터의 "이미지 생성 참고 설명(artRef)" 필드에 넣으면
"📋 프롬프트 생성" 버튼이 공통 스타일 + 등급/역할 키워드를 합쳐 완성 프롬프트를 만들어 줍니다.

> 출처: 나무위키 등장인물 문서 + 로스트아크 인벤 카드 일러스트 관찰.
> `⚠ 공식 일러 확인 필요` 표시는 문서에 외형 서술이 부족한 인물 — 인벤 카드 DB(https://lostark.inven.co.kr/dataninfo/card/)나
> 인게임 스크린샷을 직접 보고 PROMPT를 보완하세요. 지어낸 외형은 넣지 않았습니다.
>
> 저작권: 실제 게임 캐릭터를 모티프로 한 팬아트 성격의 에셋입니다. 개인/비상업 용도로만 사용하고,
> 공개 배포 시에는 스마일게이트의 2차 창작 가이드라인을 확인하세요.

표기: **[역할 제안]** 아군 타워 / 적 / 보스 · 등급 · 물리/마법
